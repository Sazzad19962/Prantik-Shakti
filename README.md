# Prantik-Shakti

প্রান্তিক শক্তি লিমিটেড (Prantik Shakti Limited)-এর বাংলা ওয়েবসাইট।

- একক পাতার স্থির (static) ওয়েবসাইট: `index.html`
- মোবাইল-উপযোগী, লাইট/ডার্ক থিম সমর্থিত
- GitHub Pages-এ সরাসরি প্রকাশযোগ্য (Settings → Pages → Branch: `main`, folder: `/`)

## প্রকাশের আগে যাচাই/সংযোজন প্রয়োজন

- RJSC নিবন্ধন (Certificate of Incorporation) নম্বর ও কোম্পানির ই-টিআইএন
- ট্রেড লাইসেন্সের নবায়ন (বর্তমান লাইসেন্সের মেয়াদ ৩০ জুন ২০২৬)
- BMET রিক্রুটিং লাইসেন্স নম্বর (প্রাপ্তির পর)
- PSTC কোর্স তালিকা, অবকাশ কেন্দ্রের অবস্থান ও বুকিং তথ্য
- লোগোর মূল ফাইল (বর্তমানে একটি অস্থায়ী প্রতীক ব্যবহৃত)
